# PiBook has moved

PiBook is now **InkDeck for Raspberry Pi** and lives in the
[Book32 repository](https://github.com/rolohaun/Book32), in the
[`pi/` folder](https://github.com/rolohaun/Book32/tree/main/pi).

This repository is archived and no longer updated. The new version fixes many
PiBook bugs, runs from any folder and user name, and shows chapters while
reading. To install or update, follow the
[InkDeck for Raspberry Pi guide](https://github.com/rolohaun/Book32/blob/main/pi/README.md).
Its installer moves your books, reading positions, to-dos and settings over
from an existing `~/PiBook` folder.
